# Contributing to PHPAML Data

Thank you for improving typed persistence for PHPAML and standalone PHP projects.

Search existing issues first. Report vulnerabilities privately through a GitHub Security Advisory. Never include database credentials, production data, connection strings, dumps, or unredacted environment files.

Create a focused branch, add tests for behavior changes, update English and French documentation when shared concepts change, and run `composer test`. Database-specific changes should also run the relevant integration checks described in [qa/README.md](qa/README.md). Discuss new drivers, public APIs, or architectural changes in an issue first.

Contributions are licensed under the [MIT License](LICENSE), and existing copyright notices must be preserved.

## Français

Les corrections et améliorations ciblées sont bienvenues. Exécutez `composer test` et les intégrations concernées, ne publiez aucune donnée ou connexion sensible et gardez les documentations anglaise et française alignées. Toute contribution est distribuée sous licence MIT.
