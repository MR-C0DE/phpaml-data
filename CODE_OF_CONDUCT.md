# Code of Conduct

PHPAML contributors, maintainers, and community members are committed to a welcoming, respectful, and harassment-free community. Discuss ideas and code without attacking people, welcome different experience levels, provide actionable feedback, and respect privacy.

Harassment, discrimination, threats, sexualized attention, personal attacks, trolling, doxxing, and deliberate disruption are not tolerated. This code applies wherever someone represents PHPAML. Report concerns privately through [SECURITY.md](SECURITY.md). Maintainers may remove content or restrict participation. Retaliation is prohibited.

## Français

La communauté PHPAML s’engage à offrir un environnement accueillant, respectueux et sans harcèlement. Les désaccords doivent porter sur les idées et le code. Signalez confidentiellement tout problème par le moyen indiqué dans [SECURITY.md](SECURITY.md). Les représailles sont interdites.
